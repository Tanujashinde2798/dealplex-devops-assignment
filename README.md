# DevOps Candidate Assignment

## Project Overview

This project demonstrates a basic DevOps workflow for a Python Flask web application.

The application is containerized using Docker, tested using Pytest, automatically tested and built using GitHub Actions, and deployed locally on Kubernetes using Kind.

## Technologies Used

- Python
- Flask
- Pytest
- Docker
- Git
- GitHub
- GitHub Actions
- Kubernetes
- Kind
- kubectl
